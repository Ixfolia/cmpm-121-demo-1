This is the starter code project for the `Demo 1` project in CMPM 121, Game Development Patterns, at UC Santa Cruz (fall quarter, 2024). Students should incrementally modify this project, tracking their progress with git, to develop an incremental game of their own unique design.

Buttons lighting up green was inspired by Jackie's project: https://jhuan280.github.io/cmpm-121-demo-1/

Having an image as the main button and making it enlarge/have an animation is inspired by: https://rozy-dixon.github.io/cmpm-121-demo-1/
